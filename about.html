How I work

My development philosophy

Four principles that shape the way I learn, write code, and approach every project.

01

Learn by building

Tutorials start the journey; projects finish it. I learn fastest by shipping something real, testing it, and improving it.

02

Solve real-world problems

I care about software that answers a genuine need — like Sema for live audience questions and Gebeya for tracking market prices.

03

Write clean, maintainable code

Readable names, small pieces, and meaningful structure. Code should be easy for the next person — or future me — to understand and change.

04

Never stop learning

Technology moves, and curiosity should move faster. I make room for new tools, honest feedback, and better habits every semester.
